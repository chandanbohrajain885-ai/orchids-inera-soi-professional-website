## USER SIDE REQUIREMENTS

When a visitor clicks "Verify Certificate", open a clean and professional page.

Page Heading:
"Certificate Verification Portal"

Sub Heading:
"Verify the authenticity of certificates issued by Inera Software."

Display ONLY:

1. Certificate Number Input Box

   * Placeholder Text:
     "Enter Certificate Number"

2. Search Button

   * Text:
     "Verify Certificate"

No unnecessary content, menus, forms, advertisements, or extra fields.

The system must allow:

* Alphabets
* Numbers
* Special Characters
* Alphanumeric combinations

---

## SEARCH FUNCTIONALITY

When the user enters a certificate number and clicks Search:

The system must search the certificate database.

If certificate exists:

Display a professional verification card containing:

✓ Certificate Verified Successfully

Name:
[Candidate Name]

Certificate Number:
[Certificate Number]

Specialization:
[Specialization / Domain]

Date of Issue:
[Date]

Status:
VALID CERTIFICATE

Display the candidate name prominently in large bold professional styling.

Use a green verified badge/icon.

---

## IF CERTIFICATE NOT FOUND

Display:

Certificate Not Found

The entered certificate number does not exist in our records.

Please contact Inera Software for assistance.

Use red styling.

## ADMIN PANEL REQUIREMENTS

Create a dedicated Admin Section named:

"Certificate Management"

Only Admin can access it.

Create a table with columns:

1. Candidate Name
2. Certificate Number
3. Specialization
4. Date of Issue

Admin Features:

✓ Add New Certificate
✓ Edit Existing Certificate
✓ Delete Certificate
✓ Search Certificate
✓ Save Changes

Add "+" button for:

* Adding new rows
* Adding new certificate records

Changes saved by admin must immediately update the verification database.

No coding changes should be required.

## DATABASE REQUIREMENTS

Every certificate record must store:

* Candidate Name
* Certificate Number
* Specialization
* Date of Issue

Certificate Number must be unique.

Duplicate certificate numbers should not be allowed.
